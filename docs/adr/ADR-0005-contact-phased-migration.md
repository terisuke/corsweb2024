# ADR-0005 Contact を段階移行（Phase1 SSGFORM 継続＋PP明記/同意、Phase2 自社チャットボット・GCP集約・LLM非依存）

## ステータス: Accepted (2026-06-13)

## 背景
- 現状 `src/components/contact/ContactForm.astro` は外部フォーム SSGFORM（ssgform.com）に PII を送信・保管。reCAPTCHA v2 併用。**同意・利用目的・PPリンクなし**で、相談種別は旧事業のまま。
- 個人情報の取り扱いを社内『個人情報保護方針(案)』に整合させ、対外表現ガードレール（ADR-0007）と法的露出最小化を満たす必要がある。
- 不要な営業メッセージの抑制・PII の自社管理（越境回避）への移行が中期方針。

## 決定
Contact を **段階移行**する。
- **Phase1（Wave1）＝SSGFORM 継続**。ただし以下を追加する：
  - プライバシーポリシーに SSGFORM への第三者提供／委託（サーバ所在国に応じ越境移転）を明記。
  - フォームに利用目的明示＋PPリンク＋同意導線（チェックボックス required もしくは「送信＝同意」明記）を追加。
  - 相談種別を旧事業3区分から新6区分（Grift・AI見積／AI受託開発／AI顧問・AI研修／ローカルLLM・機密AI／共創パートナー・採用／その他）に更新。
- **Phase2（Wave2）＝自社 AI チャットボットに置換**。
  - GCP（Cloud Run）に集約し PII を国内管理（越境回避）、営業／スパムを AI 一次フィルタ＋人手エスカレーション、ログはモニタリング規程準拠。
  - **LLM プロバイダは非依存**（gemini に固定せず、OpenAI/Anthropic/セルフホスト OpenAI 互換 API も想定）。
  - これに合わせ PP を再更新。詳細仕様は Wave2 で設計。

## 理由
- SSGFORM 即時撤去は公開を遅らせるため、Phase1 は継続しつつ PP 明記＋同意導線で法的露出を最小化（スピード優先）。
- Phase2 で自社チャットボットに置換することで、PII を国内管理し越境を回避、営業メッセージ抑制と人手エスカレーションを両立できる。
- LLM プロバイダ非依存とすることで、特定ベンダーへのロックインと将来のコスト／可用性リスクを回避する。

## 影響
- Phase1: SSGFORM のデータ保管国が PP 越境判断（28条）の前提。未確定の間は保守的に第三者提供・委託として記載（寺田／弁護士・未検証）。reCAPTCHA と同意導線を併存させ送信を成立させる。
- Phase2: GCP Cloud Run の PII 保管国・ログ・プロンプトインジェクション対策・PP 再更新が新規設計対象。Wave1 の SSGFORM 越境とは別の越境判断が必要。
- 弁護士（安藤）レビューは完成後に実施し指摘を修正 Issue 化（公開前ゲートにしない／ADR-0007 と整合）。
- Wave2 のチャットボット PII は CMS コンテンツ DB（ADR-0003 Turso）には置かない。

## 代替案
- **即時に自社チャットボットへ全面置換**: Wave2 の設計・GCP 構築が未着手で公開を遅らせるため却下。Phase1 で土台を整え段階移行する。
- **SSGFORM 継続のまま据え置き（同意導線なし）**: 個人情報保護方針・法的露出の観点で不可。
- **特定 LLM（gemini）固定**: ベンダーロックイン・コスト／可用性リスクのため非依存方針を採用。
