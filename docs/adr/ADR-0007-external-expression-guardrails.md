# ADR-0007 対外表現ガードレール（ISMS「整備中」・Pマーク/SCS不採用・旧事業撤去・社名「Cor.株式会社」統一）

## ステータス: Accepted (2026-06-13)

## 背景
- HP刷新にあたり、認証・セキュリティ・事業内容・社名の対外表現に法的・信頼性のリスクがある。誇大表現・未取得認証の主張・旧事業の残存・社名表記ゆれを公開前に統制する必要がある。
- 実査で判明した実在ライブ違反: `Layout.astro` の FAQ JSON-LD に旧事業「IT戦略コンサルティング」が実在（116-147行）、`i18n.ts`＋`ProductsTable.astro` に TapForge/BoltSite/IoTRealm が実在、`ContactForm.astro` に同意導線なし。
- 参考フォルダ（C案手直し版）の「ISMS-SCS布石」「ギャップ分析」には Pマーク・SCS★ 記述があり、公開実装に取り込んではならない。

## 決定
公開文面・構造化データ・画像・メタの対外表現ガードレールを以下に統一する。
- **ISMS は「整備中」表現のみ**。「取得済み／認証取得」は禁止。取得日（"2026年12月取得"）・審査機関名（SGS 等）は断定しない。読み替え基準：「2026年7月よりISMS運用を開始し、認証取得を目指して整備中」。
- **プライバシーマーク（Pマーク）は公開文面から完全除外**（「取得推進中」も書かない）。**SCS評価制度（★等）は公開掲載しない**。
- **旧事業（TapForge / BoltSite / IoTRealm / IoT / IT戦略コンサル）を全撤去** → 確定事業内容「AIソリューションの企画・要件定義・開発・運用、及び付随する経理・財務業務」。FAQ JSON-LD の「IT戦略コンサル」も除去。
- **社名表記を「Cor.株式会社」に全箇所統一**（ドット位置の不統一を解消）。会社概要・特商法・privacy・JSON-LD で整合。
- JSON-LD `Organization` に `hasCredential` を使わない・認証ロゴ／登録番号を出さない。福岡100選エンブレム・顧問弁護士実名・審査機関名は公開可能日・許諾確認後まで非表示（フラグ／環境変数で制御）。
- 絶対表現（「すべての顧客情報を完全に守る」「情報漏えいは起きない」等）禁止。架空 Testimonials/FAQ・顧客名／案件名の無許諾掲載禁止。Grift は「参考見積もり」とし「確定見積もりを出す」断定をしない。

## 理由
- 未取得認証の主張・誇大表現は法的・信頼性リスクであり、ISMS（整備中）の運用実態と乖離させない。
- 旧事業の残存は確定事業内容と矛盾し、対外的な誤認を生む。社名表記ゆれは法定文書・構造化データの一貫性を損なう。
- 弁護士レビューは完成後に行うため（ADR-0005）、公開前は本ガードレールで法的露出を機械的に最小化する。

## 影響
- 公開対象（src の .astro/.ts ＋ public）に対し禁止語の全文検索ゲートを設け、ヒット0 をマージ条件化する。禁止語例：`TapForge|BoltSite|IoTRealm|IoT|IT戦略|戦略コンサル|プライバシーマーク|Pマーク|SCS|★取得|ISMS取得済|2026年12月取得|SGS|hasCredential`、および公開可能日までの福岡100選。
- 非エンジニア自由投稿（StudioCMS／ADR-0001）の本文・タグ・カテゴリにも DON'T 表現の運用ルール＋投稿者チェックリストを適用し、可能なら投稿フロー／CI に禁止語スキャンを組み込む。既存 blog 本文も移行時に全文 grep。
- privacy／特商法／会社概要／Organization JSON-LD で社名「Cor.株式会社」を統一する。
- レビュー布陣: 諫山＝ISMS／SoA 整合・誇大チェック、Nagi＝UX、安藤弁護士＝完成後の法的レビュー。

## 代替案
- **ISMS「取得済み／2026年12月取得」を掲載**: 運用実態と乖離し法的・信頼性リスクが高いため却下。
- **Pマーク／SCS を「取得推進中」として掲載**: 制度未確定・未開始のため誤認を招き却下。
- **旧事業を一部残す（Products 併存）**: 確定事業内容と矛盾し禁止語ゲートに抵触するため却下（Products 廃止→/works 統合）。
